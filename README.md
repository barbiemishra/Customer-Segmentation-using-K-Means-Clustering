# Customer Segmentation using K-Means Clustering

Key things I learned:

1. Why feature scaling (StandardScaler) matters before clustering — unscaled features distort distance-based algorithms
2. Using the Elbow Method to systematically choose the number of clusters instead of guessing
3. How k-means++ initialization avoids poor local minima compared to random centroid placement
4. Translating cluster outputs into business-readable customer segments
